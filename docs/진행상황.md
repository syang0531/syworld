## 1. 이 저장소가 하는 일 · 하지 않는 일

**모드팩은 CurseForge 앱이 만든다.** CurseForge 모드팩 규정(Moderation Policies, Minecraft 절)이
"앱으로 만든 형식"을 요구하고 "앱이 만든 manifest를 손으로 고치는 것"을 금한다. 그래서 이 저장소는

- 팩을 **만들지 않는다** — 앱에서 내보낸 zip을 `pack/`에 둔다
- zip을 **고치지 않는다** — `tools/publish.py`는 manifest를 읽어 검사만 하고, 파일은 그대로 올린다
- **배포는 한다** — 태그 → 검사 → CurseForge 업로드 → GitHub Release

```powershell
python tools\publish.py 1.0.0 --dry-run   # 검사만 (토큰 불필요)
python tools\publish.py 1.0.0 --changelog # CHANGELOG 구간
python tools\publish.py 1.0.0 --path      # 그 버전의 zip 경로
python tools\gen_logo.py                  # 로고
```

## 2. 파일

| 파일 | 역할 |
|---|---|
| `pack.json` | 팩 이름 · CurseForge 프로젝트 id(`1708139`, slug `syworld`) · Minecraft 버전 · 로더 · **들어가야 할 SY 모드 목록** |
| `pack/*.zip` | 앱에서 내보낸 팩. 버전마다 하나. 파일 이름은 상관없고 manifest의 `version`으로 찾는다 |
| `tools/publish.py` | 검사 + 업로드. 표준 라이브러리만(로컬 · Actions 같은 코드) |
| `tools/gen_logo.py` | 로고. Pillow, 4배 슈퍼샘플링 — 가족 로고와 같은 방식 |
| `.github/workflows/release.yml` | `v*` 태그 → 검사 → 업로드 → GitHub Release. 수동 실행(dry run)도 된다 |
| `docs/curseforge/등록정보.md` | CurseForge 폼 문구 · 분류 · 로고 설명 |

## 3. 검사 항목 (`publish.py`)

- `pack/`에서 manifest `version`이 요청 버전인 zip이 **정확히 하나**
- manifest `name`이 `SY World`, Minecraft가 `26.2`, 로더가 `neoforge-*`
- `pack.json`의 `family`에 있는 SY 모드가 **전부** manifest에 있다 — 새 SY 모드는 `family`에 먼저 넣는다
- `CHANGELOG.md`에 `## <버전>` 구간

## 4. 결정 · 함정

- **새 SY 모드가 나오면**: 앱에서 프로필에 추가 → `pack.json` `family`에 한 줄 → 내보내기 → CHANGELOG → 태그.
  로고의 섬에도 자리를 하나 준다(`gen_logo.py`).
- **프로필은 둘**: 가족과 플레이하는 건 CurseForge에서 설치한 **SY World**, 팩을 내보내는 건 **SY World (dev)**
  (1.0.0을 내보낸 옛 `NeoForge 26.2` 프로필). 월드 옮기기 · 업데이트 절차는 PUBLISHING.md C.
- **팩 안 파일은 전부 CurseForge에서 승인된 상태여야 한다.** 모드를 막 올렸으면 승인 뒤에 팩을 내보낸다.
- **시크릿은 저장소마다 따로.** 모드 저장소의 `CURSEFORGE_TOKEN`은 여기서 안 보인다.
- **업로드 경로는 아직 한 번도 안 돌았다.** 모드는 CurseForgeGradle로 올렸지만 모드팩은 `publish.py`가 업로드 API
  (`POST /api/projects/{id}/upload-file`)를 직접 부른다. 게임 버전은 Minecraft `26.2` id 하나만 보낸다
  (`/api/game/version-types`에서 slug가 `minecraft`로 시작하는 유형 → `/api/game/versions`에서 이름 `26.2`).
  CurseForge가 더 요구하면 HTTP 오류 본문이 그대로 찍힌다.
- **전용 서버 지원은 문구에 쓰지 않았다.** Dungeon · Magic 문서에는 있지만 Village · Works 문서에는 없다.
  네 모드 모두 확인되면 더한다.
- **모드 이름 규칙**: 모드 저장소들은 "다른 모드 이름을 쓰지 않는다"는 규칙이 있지만, 이 팩은 이름 그대로
  SY 모드의 묶음이라 네 모드를 이름으로 소개한다.
